# MAPPA on Overleaf

`main.tex` is the sole manuscript entry point. Edit it and the shared
`includes/`, `assets/` and `figs/` in this project.

1. Choose New Project > Upload Project and upload `mappa_overleaf.zip`.
2. Select `main.tex` as the main document.
3. Select the **XeLaTeX** compiler, then Recompile.

The export contains the same source used for the local PDF, including the
supplement, bibliography, figures, class and custom font. No Python processing
or benchmark data is required on Overleaf.
