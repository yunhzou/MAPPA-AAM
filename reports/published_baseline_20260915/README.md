# Published MAPPA baseline (competition disabled)

The published method is one-seed cut sweep followed by separate bond-event decoding. The optional `rxn_core.competition` module remains experimental and is not called. Golden results already measured this baseline and are unchanged.

The 140-coordinate comparison uses cap 2,000. MAPPA finds fewer events than SLAP sweep in four reactions and equal counts in 136; against native SLAP the counts are 15 and 125. At equal minima, MAPPA retains 158/164 SLAP-sweep patterns and 138/140 native-SLAP patterns. Across the full evaluation windows it retains 162/168 and 151/160, respectively. There are 300 baseline event classes, including 166 at MAPPA's own minima. Mappings are unverified; these are bond-event comparisons, not mapping accuracy.

These sets are selected using the explicit baseline class IDs and complete-window certificates in the archived final-family audit, not by assuming every repair witness is new. The original `reports/current_validation_20260912/drivers/audit_coordinate.py` loads the baseline first, records its family boundary, and extracts its event IDs from completed per-family journals. It checks completion for every family in the full catalogue, so the baseline subset is certified independently of any extension-only patterns. `baseline-windows.json.gz` contains the retained witnesses. `coordinate_minima.json` derives every comparison from those sets. `manifest.json` pins the original evidence hashes. No AAM search is rerun. The optional fresh decoder verification completed 53 cases with identical class sets and family counts before it was stopped following watchdog failures; its partial results are separate in `verification.json`. The paper does not report this partial run as complete decoder timing, and does not reuse the old combined decoder timing.

Timing in the revised paper covers the recorded sweep-search and SLAP mapping/refinement stages on the same CPU. Baseline-only decoder timing is not reported. Search cap 100 returns full mappings in 138/140 reactions; cap 2,000 returns them in 140/140. Only this search-completion fact is carried forward from the archived paired cap study, not its old combined event sets.

The rebuilt film in `film/` uses only baseline Golden case 15. Its 44 unordered branches contain 96 families and nine event classes through six events. The two displayed witnesses are the terminals of the two recorded growth paths, and decode to distinct canonical event classes. Two classes are displayed, including one equivalent to the Golden reference. Existing takeover experiments remain archived elsewhere and are excluded from the published method.

Run `python reports/published_baseline_20260915/audit.py` for the read-only evidence audit and `python reports/published_baseline_20260915/film/verify.py` for film membership/reference checks. The optional `decode_baseline.py all` driver expects `MAPPA_ARCHIVE_ROOT` to point to the original campaign directory containing `runs/coordinate/seed1/case*/R_to_P/cuts/aam.pkl.gz`; it uses three workers and five-minute per-case watchdogs. This expensive verification is not needed to rebuild the figures or film.

A subsequent [fresh end-to-end timing pass](../final_end_to_end_20260916/README.md) measures final search plus public decoding on all 140 inputs. It completes 138 cases and reports the two watchdog interruptions explicitly; the earlier archived complete-window certificates remain the basis of the full coverage counts.
